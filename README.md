# 3·2·1 GO — Daily WOD (@321go.wod)

Her gün bir WOD paylaşan Instagram sayfası. Diğer projelerden tamamen bağımsız.

| Klasör / dosya | Ne işe yarar |
|---|---|
| `brand.json` | İsim, kullanıcı adı, renkler (her WOD türünün kendi rengi), hashtag'ler |
| `brand/` | Profil fotoğrafı ve marka dosyaları |
| `library/photos`, `library/videos` | Envato'dan indirilen görseller (lisans projesi: **321GO Instagram**) |
| `wods/weekNN.json` | Haftanın WOD'ları (RX / Scaled / No gear) |
| `template.html` | Kart tasarımı (1080×1350) |
| `render.py` | `python render.py wods/week01.json` → `out/week01/` içine görseller + `captions.md` + `grid.png` |
| `history.json` | Paylaşılan WOD'ların kaydı (tekrar önleme) |
