# 3·2·1 GO — Programming rules

Every new week (`wods/weekNN.json`) must follow these rules. Check `history.json` first so nothing repeats.

## Spirit
- **Fun and doable, never random.** Every WOD should be something a real box would happily put on the whiteboard: a clear stimulus, sensible loads, a rep scheme that flows.
- **Everyone trains.** Every WOD has RX, Scaled and No gear versions with the *same stimulus* (similar time domain and feel).
- Short, honest names. A clear target (time / rounds) so people know if they nailed the stimulus.

## Weekly rhythm (mix it up, keep the shape)
| Day | Default | Notes |
|---|---|---|
| Mon | FOR TIME | 8–15 min, simple couplet/triplet |
| Tue | EMOM | 12–20 min, 3–4 stations |
| Wed | AMRAP (carousel) | 12–20 min, pacing lesson |
| Thu | LADDER / strength-biased | moderate loads, never grinding |
| Fri | PARTNER (carousel) | "bring a friend", synchro finisher |
| Sat | HYBRID (Hyrox-style) **or** CHIPPER | alternate weeks; long steady session |
| Sun | TABATA / bodyweight | zero equipment, 12–20 min |

- **HYBRID / Hyrox-style at least every other week**, sometimes as a short "compromised running" piece mid-week too (e.g. 4 × 500 m run + 20 wall balls). Use real Hyrox stations: SkiErg, sled push, sled pull, burpee broad jumps, row, farmers carry, sandbag lunges, wall balls (6/4 kg). Write "HYROX-style", never imply official affiliation.
- Benchmark-style classics are fine as inspiration, but write original WODs (own names).

## Balance checks (per week)
- Each pattern 2–3× max: squat, hinge, push, pull, core, monostructural (run/row/ski/bike).
- Never the same hard pattern on back-to-back days (e.g. heavy hinge Thu → no swings Fri).
- Time domains: at least one ≤10 min, one 15–20 min, one ≥25 min.
- Loads: RX ♂/♀ in kg, moderate (e.g. DL 80/55 for high reps, power clean 60/40, KB 24/16, DB 22.5/15, WB 9/6; Hyrox WB 6/4).

## Captions (English)
`hook` (1 line, emoji ok) → `story` (2–3 friendly sentences: why it's fun / how it feels) → workout block →
Scaled / No gear / Target → `tip` (one practical coach tip) → `question` (invites comments) → CTA → hashtags (type tags + base tags from brand.json).
