# 3·2·1 GO — Programming rules

Every new week (`wods/weekNN.json`) must follow these rules. Check `history.json` first so nothing repeats.

## Spirit
- **Hard, real CrossFit — but everyone can do it.** (Owner's rule, 2026-10-16, applies from week 3 on; weeks 1–2 stay as they are.) Program like a serious box: barbell (clean, snatch, thruster, front/back squat, deadlift, overhead squat, push press/jerk), gymnastics (pull-ups, C2B, toes-to-bar, HSPU, bar/ring muscle-ups, double-unders), KB/DB, wall balls, box jumps, burpee variants, row/bike/ski/run. Real volume and intensity — the RX version should feel like a proper CrossFit WOD, the Scaled and No gear versions make it doable for everyone.
- **No filler moves.** Do NOT program mountain climbers, jumping jacks, high knees, flutter kicks, plank jacks, crunches or similar "cardio class" moves. Even No gear substitutes use real movements: burpees, air squats, push-ups, lunges, jump squats, sit-ups, burpee broad jumps, runs, tuck jumps, pistols/step-ups.
- **Fun and doable, never random.** Every WOD should be something a real box would happily put on the whiteboard: a clear stimulus, sensible loads, a rep scheme that flows.
- **Everyone trains.** Every WOD has RX, Scaled and No gear versions with the *same stimulus* (similar time domain and feel).
- Short, honest names. A clear target (time / rounds) so people know if they nailed the stimulus.

## Weekly rhythm (mix it up, keep the shape)
| Day | Default | Notes |
|---|---|---|
| Mon | FOR TIME | 8–15 min, barbell-centric couplet/triplet, sprinty |
| Tue | EMOM | 12–20 min, barbell or gymnastics skill under fatigue |
| Wed | HYBRID short (carousel) | 15–25 min "compromised running" (e.g. 5 × 500 m run + 20 WB + 10 burpee broad jumps) |
| Thu | AMRAP / LADDER | 12–20 min, moderately heavy, gymnastics + barbell |
| Fri | PARTNER (carousel) | "bring a friend", synchro finisher, real CrossFit volume |
| Sat | HYBRID long (carousel) | 30–45 min HYROX-style race piece (runs + stations) |
| Sun | BODYWEIGHT burner | zero equipment but hard (burpees, push-ups, squats, lunges, runs, pull-ups if a bar exists) — Tabata or chipper format |

- **HYBRID / Hyrox-style 2 days every week** (one short mid-week, one long on Saturday). A CHIPPER can replace a non-Hyrox day now and then. Use real Hyrox stations: SkiErg, sled push, sled pull, burpee broad jumps, row, farmers carry, sandbag lunges, wall balls (6/4 kg). Write "HYROX-style", never imply official affiliation.
- Benchmark-style classics are fine as inspiration, but write original WODs (own names).

## Balance checks (per week)
- Each pattern 2–3× max: squat, hinge, push, pull, core, monostructural (run/row/ski/bike).
- Never the same hard pattern on back-to-back days (e.g. heavy hinge Thu → no swings Fri).
- Time domains: at least one ≤10 min, one 15–20 min, one ≥25 min.
- Loads: RX ♂/♀ in kg at standard CrossFit RX (e.g. thruster 43/30, power clean 61/43, snatch 43/30 for cycling, DL 100/70 for moderate reps, OHS 43/30, KB 24/16, DB 22.5/15, WB 9/6; Hyrox WB 6/4, sled per Hyrox Open). Scaled ≈ 60–70 % of RX with simpler gymnastics.
